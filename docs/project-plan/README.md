# CoreBankX QA Lab — Project Plan

## Purpose

This document contains the master project planning information for CoreBankX QA Lab.

## Project Vision

CoreBankX QA Lab will simulate a modern digital banking platform and demonstrate end-to-end Quality Engineering practices.

## Primary Areas

- Banking Domain
- Internet Banking (INB)
- Mobile Banking (MOB)
- Manual Testing
- ISTQB
- Database Testing
- Web Automation
- API Testing
- Mobile Testing
- BDD
- Performance Testing
- Security Testing
- AI QA
- CI/CD
- DevOps
- Test Reporting
- Data Analytics
- Interview Preparation

## Development Approach

The project will be developed incrementally.

### Phase 1
Project foundation and architecture.

### Phase 2
Banking application development.

### Phase 3
Manual testing and ISTQB-based test design.

### Phase 4
Automation frameworks.

### Phase 5
API and BDD automation.

### Phase 6
Mobile, performance and security testing.

### Phase 7
AI QA, CI/CD, Docker and analytics.

### Phase 8
Interview Academy, documentation and portfolio demonstrations.
